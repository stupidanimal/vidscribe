# video-to-summary

Transcribe video/audio to text and summarize content. Supports 99+ languages, works 100% locally (no API keys needed).

## What it does

```
Video/Audio → ffmpeg extracts audio → faster-whisper transcribes → LLM summarizes
```

## Features

- Local transcription (no cloud, no API keys, no data leaves your machine)
- Support 99+ languages (English, Chinese, Japanese, etc.)
- Auto-detect video vs audio input
- Download from URL via yt-dlp (YouTube, Bilibili, etc.)
- Batch mode (process entire folder)
- Smart caching (skip if transcript already exists)

## Requirements

- Python 3.10+
- ffmpeg (`winget install ffmpeg`)
- faster-whisper (`pip install faster-whisper`)
- yt-dlp (optional, for URL downloads: `pip install yt-dlp`)

## Quick Start

```bash
# Install dependencies
pip install faster-whisper yt-dlp

# Transcribe a local video
python scripts/transcribe.py "video.mp4" --model base

# Transcribe from URL
python scripts/transcribe.py "https://youtube.com/watch?v=..." --model small

# Batch process a folder
python scripts/transcribe.py "./videos/" --batch --model tiny
```

## Model Selection

| Model | Speed (10min) | Quality | RAM | Best for |
|-------|--------------|---------|-----|----------|
| tiny | ~30s | Draft | 1GB | Quick preview |
| base | ~1min | Good | 1GB | General use |
| small | ~3min | Better | 2GB | Non-English |
| medium | ~10min | High | 5GB | Production |
| large-v3 | ~30min | Best | 10GB | Max accuracy |

## Output

Two files per video:
- `<name>_transcript.txt` — timestamped raw text
- `<name>_summary.md` — structured summary (generated by LLM)
